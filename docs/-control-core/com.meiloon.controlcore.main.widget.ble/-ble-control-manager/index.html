BleControlManager

open class BleControlManager

藍牙與 MQTT 通訊控制中樞。 本類別是與美隆硬體設備進行互動的核心入口。它負責處理： - 多協定連線管理 (BLE, ESP32/BluFi, Jieli, MQTT)。 - 指令封裝與發送 (Protocol)。 - 接收設備回傳資料的解碼與廣播。 ### 通訊協定 (Protocol) 說明： SDK 的指令協定基於特定的字串格式，通常為 "CommandName|Param1|Param2"。
