open class EQData
參數化等化器 (Parametric Equalizer, PEQ) 的單一波段資料實體。 此物件代表了一個 PEQ 濾波器的完整參數，包含頻率、增益、Q 值以及濾波器類型。 在與硬體通訊時，可透過 toBytes 將其轉換為符合美隆通訊協定的 8-bytes 位元組陣列。 ### 參數定義： - **頻率 (Freq)**: 中心頻率或截止頻率 (Hz)。 - **增益 (Gain)**: 提升或衰減的音量 (-12dB ~ +12dB)。 - **Q 值 (Quality Factor)**: 控制影響頻段的寬度。Q 值越大，影響範圍越窄。 - **類型 (Type)**: 0 代表標準 PEQ，其他數值可代表 High/Low Shelf 等。
